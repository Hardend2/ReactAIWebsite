## 1. Projectbeschrijving
NeuroWerk is een informatieve, statische React-website in het Nederlands.
Ze legt uit hoe neurodiversiteit (o.a. ADHD, autisme, dyslexie, dyspraxie)
de zoektocht naar werk beïnvloedt, en geeft tips aan werkzoekenden en werkgevers.

## 2. Maatschappelijke verantwoording
- **Probleem:** neurodivergente werkzoekenden stuiten op standaard
  sollicitatiegesprekken, vage vacatures, prikkeloverbelasting, stigma en
  onzekerheid over het delen van hun diagnose.
- **Kans:** sterktes zoals patroonherkenning, creativiteit, diepe focus en
  oog voor detail blijven vaak onopgemerkt.
- **Leemte:** betrouwbare, toegankelijke Nederlandstalige informatie over
  zowel voor- als nadelen vind je zelden op één plaats.
- **Doelgroep:** werkzoekenden in Vlaanderen (primair), werkgevers en
  HR (secundair), naasten, coaches en jobbegeleiders (tertiair).

## 4. Installatie en gebruik
Vereisten: Node.js (LTS) en pnpm.

```bash
git clone https://github.com/TODO-gebruiker/TODO-repo.git
cd TODO-repo/ITChallengesReactProject
pnpm install
pnpm dev        # lokale ontwikkelserver
pnpm build      # productiebuild
pnpm preview    # productiebuild lokaal bekijken
pnpm lint       # oxlint
pnpm test       # Vitest
pnpm test:e2e   # Playwright (installeert de testbrowser indien nodig)
```

## 5. Technologieën
React, TypeScript, Vite, pnpm, React Router, CSS (design tokens), oxlint, Prettier,
Vitest, React Testing Library, axe. Hosting: Netlify.
